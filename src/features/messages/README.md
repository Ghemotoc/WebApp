# Messages

One-to-one private messages and message requests. Built by S1-E9-01 (bundle MESSAGES, part b) on the rule from S1-E9-03 (`can_message()`). Board: `design/boards/Messages.dc.html` (5.5).

- `components/MessagesPage.tsx`: `/messages` and `/messages/:handle` (the other person's username). With no chat open (board E12): the title, New chat and Message settings, then the chats beside the "Pick a chat" card. With a chat open (board E13) three columns from 1024 px (`ChatList`, `ChatPanel`, `AboutChatPanel`); one at a time below that, under `ChatFocusBar`.
- `components/ChatList.tsx`: with no chat open, the Chats and Requests switch (a `SegmentedControl`; "Requests · 2" while some wait), `MessagesRulesNotice` and the rows (`ChatListItem`, `ChatAvatar`; an unread row is bold with "New"); beside an open chat, every chat and request alone, newest first.
- `components/ChatPanel.tsx`: one chat: `ChatMessages` (bubbles, Report beside the other person's), then `RequestActions` for a request to the reader, `MessageComposer` when they may write, or a note ("waiting in their requests", or the neutral "isn't taking messages right now").
- `api/messages.ts` and `hooks/useMessages.ts`: `my_conversations()`, `conversation_with()`, `send_message()`, `answer_message_request()`, `mark_conversation_read()` and `my_message_settings()`. New messages arrive by asking again (5 s in a chat, 15 s for the list). The top bar's count, `unread_message_count()` every minute, is in its own small `hooks/useUnreadMessageCount.ts`, because the top bar is on every page and the chapter reader has a script budget (`e2e/reader-performance.spec.ts`; G8c).
- Text: `src/locales/{ro,en}/messages.json`, loaded with the page (`registerMessagesTranslations.ts`); the top bar's words are in `common.json`.
- The database side: `supabase/migrations/…_s1_e9_01_private_messages.sql`; tests `206` and `e2e/messages.spec.ts`.
- `components/ChatHeader.tsx` and `ChatBlockDialog.tsx`: Block and Report in the chat header (S1-E9-02); the moderator reads a reported message with up to 20 before it in `src/features/moderation/components/CaseMessagePanel.tsx`. The header also shows the writer line (`hooks/usePartnerLine.ts`, from `conversation_with().latest_story`, which `chat_partner_story()` picks from the stories the reader may open; BOOKS-4). Below 1024 px `ChatFocusBar.tsx` is the one bar: Back to Messages, the name with the kind of writer and More, which shows the same `ChatActions`.
- `components/MessageSettingsSection.tsx`: Settings › Messages: who may start a chat (everyone, people you follow, nobody) and, for 16 and 17-year-olds, "Let adults message me" (S1-E9-04). `MessageSettingsLink.tsx` is the "Change" and "Message settings" link to it.
- `components/MessagesHeaderLink.tsx`: Messages as a 44 px icon button with a small count (1 to 9, then 9+, `CountBadge`) of chats with new messages and the full count in its name, in the phone header and (since bundle CALM-2) the wide top bar, while signed in.
- `components/DeleteChatControl.tsx`: Delete chat in About this chat, for the reader only (S1-E9-04). `hooks/useMessageSettings.ts` holds the settings and Delete chat hooks.
- The clean-up: `purge_deleted_chats()`, nightly, deletes the messages of chats both people deleted, keeping reported ones while needed (`…_s1_e9_04_message_settings_and_retention.sql`; tests `208`, `e2e/message-settings.spec.ts`). The epic check is `e2e/epic-s1-e9.spec.ts`.
- A shared story link (GAPS-7): `hooks/useSharedLink.ts` reads `?share=` (only a story path of this website, `src/lib/storyLinks.ts`); `MessagesPage` shows "Pick a chat" with "Don’t send", the chat's message box opens with the link, and `ChatMessages` draws story links as pressable links.
- `components/NewChatButton.tsx`: New chat and its dialog (board E12, BOOKS-4): the people the member follows whom they may write to now, from `new_chat_people()` (which asks `conversation_can_send()`); no search by username. `…_books_e12_e13_chat_partner_and_new_chat.sql`, tests `412`.
- `components/AboutChatPanel.tsx`: About this chat (board E13): Profile, You (who follows whom), Who can message you and, for 16 and 17-year-olds, Messages from adults, then the privacy line and Delete chat. A teenager whose adults switch stops the chat sees why, with Change (`conversation_with().adults_switch_stops`, `my_adults_switch_stops_chat()`).
