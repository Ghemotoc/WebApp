# Discovery

Discover and the story lists. Built by PEOPLE-2: S1-E5-01 (Discover, category and tag pages), S1-E5-09 (See all pages) and S1-E5-02 (sort and filters). PEOPLE-3 added S1-E5-03 (Popular and New and rising, popular as the default sort).

- `components/DiscoverPage.tsx`: screen 3.1 at `/discover`: the header, Featured this week (`FeaturedBand`) with "Your dashboard" (`DiscoverCards`) beside it from 1024 px, and one `DiscoverShelf` per list, in the order of the public setting `discover_shelves` (by default: following when signed in, popular, new and rising, new, completed, recently updated, public-domain classics (S1-E5-06), then each category), and "How ranking works" (the terms, section 5). Board: `design/boards/Discover.dc.html` (liquid glass board Discover since G7; no category chips there, the story page's breadcrumb links to its category).
- `components/StoryListPage.tsx`: screen 3.10 See all, one page for `/discover/all/:listKind`, `/discover/c/:categorySlug`, `/discover/t/:tag` and `/u/:handle/stories`, with `StoryListHeader`, `StoryListFilters` and `StoryGrid`. The list's ad sits high and again
  after every 10 stories (`lib/gridAdPlaces.ts`, bundle G7e).
- `components/ListedStoryCard.tsx`: the shared `StoryCard` with the writer, chapter count and status.
- `hooks/useStoryShelf.ts` (21 rows for a shelf), `hooks/useStoryList.ts` (24 a page with "Load more"), `hooks/useListTitle.ts` (eyebrow and title per list).
- `api/storyLists.ts`: the one call, `browse_stories()`.
- `lib/listAddresses.ts`: every list's address, the list behind an address and each list's own sort (`listDefaultSort()`, the same rule as the database's `list_default_sort()`); `lib/sortMemory.ts`: the sort kept for this tab; `lib/categoryAccents.ts`: each category's colour.
- `registerDiscoveryTranslations.ts`: the `discovery` text namespace, added when a discovery component first renders.
- The database side: `supabase/migrations/…_s1_e5_01_browse_stories.sql` `…_s1_e5_02_sort_options.sql` and `…_s1_e5_03_popularity_ranking.sql` (the hourly `compute_story_scores()` job and `story_scores`); tests `151`, `152` and `155`.
- `components/GreetingHeading.tsx` and `lib/greeting.ts` (S1-E2-13 with S1-E2-12, and S1-E5-12): Discover's heading for someone signed in: "Good morning, <name>." (or the birthday month or joining anniversary) under a dated eyebrow.
- "Your dashboard" (S1-E5-12, LOOK-4b): `components/DiscoverCards.tsx` with `ContinueCard`, `DraftCard` and `NewStoryCard`; `hooks/useDiscoverCards.ts` and `api/discoverCards.ts` read `my_discover_cards()`. The database side: `supabase/migrations/…_look4b_01_discover_cards.sql`; tests `305` and `e2e/discover-cards.spec.ts`.
- "Most shared this week" (IDEAS-1 part e): the list `shared` and its own sort `shared`, by the last 7 days' chapter shares (`story_shares_this_week()`); `sortChoicesFor('shared')` puts that order first. The database side: `supabase/migrations/…_ideas1_e_paragraph_links_most_shared.sql`; tests `219` and `e2e/paragraph-links-most-shared.spec.ts`.
- "Writers to follow this week" (S1-E5-11, LOOK-4c): the word `writers` in `discover_shelves` draws `components/RisingWritersShelf.tsx` with `WriterToFollowCard`; `hooks/useRisingWriters.ts` and `api/risingWriters.ts` read `rising_writers()`, which only lists writers `may_spotlight_writer()` allows. The database side: `supabase/migrations/…_look4c_02_rising_writers.sql`; tests `304` and `e2e/writers-to-follow.spec.ts`.
- "Featured this week" (S1-E5-10, LOOK-4a): `components/FeaturedBand.tsx` with `FeaturedSlide` and `FeaturedControls` opens Discover; `hooks/useFeaturedStories.ts`, `useFeaturedRotation.ts` and `api/featured.ts` read `featured_stories_now()`. The database side: `supabase/migrations/…_look4a_02_featured_picks.sql`; tests `303` and `e2e/featured-this-week.spec.ts`.
- `api/listPageBackground.ts` and `hooks/useListPageBackground.ts` (bundle G12b): the band colour an admin chose for a genre or tag page in the visitor's market, read by `StoryListHeader`.
- "Popular in" a country (MARKETS-2d): `components/PopularShelf.tsx`, `PopularInSelect.tsx` and `PopularInNote.tsx`, `hooks/usePopularIn.ts` (the countries from `popular_in_countries` and where the drop-down starts) and `lib/countryNames.ts`. `browse_stories(popular_in => …)` ranks by `story_country_scores`. The database side: `supabase/migrations/…_markets2d_popular_in.sql`; tests `359` and `e2e/popular-in.spec.ts`.
