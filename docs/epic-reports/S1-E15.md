## What works

- Every stored number is a total: no row is about a person, so the page can't list anyone.
- The return rate comes from daily totals only and the page labels it an approximation (architecture 1.7.9).
- The targets are settings, so they can change without a release.
- Counting a day again replaces it, so a re-run never doubles a number.

## Breaks found where stories meet

None. The demo content (TOOL-3) gives a return rate over 100%, because its reads are made up; real reading can't, since each chapter's later reads come from the same readers.

## Known gaps

- "Signed-up readers" counts confirmed accounts, not accounts that opened a chapter: that would need a record per reader, which we never keep (`docs/board-fixes.md`).
- Reads per day is a list, not the board's chart.
- Moderators see no numbers here yet; their queue numbers are on the moderation page.
