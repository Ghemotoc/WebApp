Open a story to hide or restrict it, change its settings and details (rating, category, tags, status, where it can be read), remove an unlawful part, see its history or download it. Staff never edit a writer’s words. There is no bulk action: each change is made on one story, with a reason the writer sees.

One owner per story. Every story is linked to its writer’s user ID. The ID is made automatically when someone signs up, it never changes and it is never shown publicly. A handle can change. The ID can’t.

Data requests. To send someone all their stories, use Data requests. It finds every story by user ID, so stories under an old handle are included.
