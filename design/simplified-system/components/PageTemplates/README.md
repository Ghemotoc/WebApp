# PageTemplates

Every screen uses one of five templates. A screen that needs something else is a design question, not a one-off.

| Template | Used for | Rules |
|---|---|---|
| Shelf page | Read, Library, story pages, genre, tag and See all pages, profile stories | The page's one glass hero, then rows of covers. |
| Desk page | Home, Write, class dashboards | The glass hero, then rows and lists, two side by side on wide screens. |
| Focus page | Reader, editor, Atlas sheets | FocusBar; paper in one column. On wide screens the reader keeps a side column: About this story, the advert, and panels opened on request. |
| Talk page | Together, threads, spaces, Messages | A list, then the conversation; side by side on wide screens. |
| Form page | Settings, story settings, joining | One column, plain section headings, one Save. |

Layout rules: one plum action per screen; no section eyebrows; glass on what floats plus one hero per page; phones first, so the wide layout adds space, never extra blocks.
